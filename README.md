# Móng Điện Gió Biển

Web app học thiết kế móng điện gió biển theo IEC 61400-3-1:2019, đối chiếu TCVN. Chạy trên iPhone, không cần máy chủ.

Cấu trúc: `index.html` (khung trang), `style.css` (giao diện), `calc.js` và `calc2.js` (tính toán), `content.js` (lý thuyết, TCVN, thuật ngữ, trắc nghiệm), `app.js` (giao diện và logic).

Đăng lên GitHub Pages: Settings → Pages → Deploy from a branch → main / root.

Lưu ý: kết quả chỉ ở mức sơ bộ để học tập, không thay thế phân tích tải tích hợp và thẩm tra độc lập.
